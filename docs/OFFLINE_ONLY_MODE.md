# Offline-Only Mode Implementation

## Описание

Реализован режим работы приложения с изоляцией данных пользователей при использовании локальной базы данных (IndexedDB). Эти изменения обеспечивают корректную работу до момента полной интеграции с backend для синхронизации.

## Реализованные изменения

### 1. Фильтрация списков по пользователю ✅

**Файл:** src/pages/Lists/ui/ListsPage.vue

**Результат:** Каждый пользователь видит только свои списки, фильтрация происходит на уровне IndexedDB по полю ownerId.

### 2. Очистка локальной БД при logout ✅

**Файл:** src/entities/user/model/user.store.ts

**Результат:** При выходе из аккаунта все локальные данные (списки, items, операции синхронизации) полностью удаляются из IndexedDB.

### 3. Синхронизация при login ✅

**Файл:** src/entities/user/model/user.store.ts

**Результат:** При входе в систему автоматически запускается синхронизация данных с сервером (если backend поддерживает).

### 4. List-items управление ✅

**Статус:** УЖЕ РЕАЛИЗОВАНО

**Возможности:**
- ✅ Создание items через RxJS
- ✅ Обновление content
- ✅ Toggle checked состояния (мгновенная обратная связь)
- ✅ Удаление items
- ✅ Оптимистичные обновления UI
- ✅ Автоматическая очередь синхронизации

## Текущее поведение

### ✅ Работает корректно:

1. **Создание списков:** Каждый список сохраняется с ownerId текущего пользователя
2. **Просмотр списков:** Пользователь видит только свои списки (фильтрация по ownerId)
3. **Logout:** Полная очистка локальных данных
4. **Login:** Попытка синхронизации с сервером (если доступен)
5. **Offline CRUD:** Все операции с lists и items работают оффлайн с optimistic updates
6. **Sync queue:** Операции сохраняются в очередь для последующей синхронизации

### ⚠️ Ограничения (требуется backend):

1. **Нет загрузки с сервера:** При login данные не загружаются с backend (только пустая БД + локальные изменения)
2. **Нет полной синхронизации:** syncService.forceSync() попытается отправить pending операции, но не получит данные обратно
3. **Нет cross-device sync:** Данные живут только локально на устройстве
4. **Нет shared lists:** Функционал sharing пока не работает корректно без backend
